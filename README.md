# 🗡️ | Slay the knight

Ce projet est un jeu **2D rogue-like** où le joueur doit se battre contre plusieurs ennemis afin de récupérer des objets tel que des **power-ups** pour survivre **le plus longtemps possible.**

## ⌨️ | Touches du jeu 

Plusieurs touches sont utilisés pour déplacer le personnage mais également la caméra :

- **Déplacement du personnage : ZQSD**
- **Déplacement de la caméra : Flèches directionnelles**
- **Attaquer : Clic gauche**

## 👨‍💻 | Comment exécuter le projet

- **Ouvrir le dossier "Engine"**
- **Cliquer sur le fichier "Engine.sln" et l'ouvrir avec Visual Studio 2026**
- **Dans l'explorateur de solution, clique droit sur "Game" > "Définir en tant que projet de démarrage"**
- **Cliquer sur la flèche verte avec "Débogueur Windows local", situé en haut de la barre de Visual Studio.**
